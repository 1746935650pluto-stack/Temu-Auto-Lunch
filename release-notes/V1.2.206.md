# V1.2.206 — 订单快速并行同步（2026-11-13）

- 每日统计默认提供“快速同步最近 100 条”，每账号最多读取一页，合并到本地记录；另设“补齐历史订单”，沿用每账号单次 20,000 条历史上限，读满时明确提示。已有历史保留，分页失败不写入半份结果。
- 不同账号同时同步，各账号内部顺序分页，继续使用后台同账号互斥和现有接口限流。重复点击不会再次提交，未配置或不可用账号跳过，部分失败不阻断其他账号。
- 新增按请求编号隔离的进度查询，显示账号完成数、页数和读取数量。每个账号成功后立即刷新当前统计；取消等待缓存过期的 16 秒延迟，后台提交后使该账号和汇总统计缓存失效。
- 保留旧订单中心调用的返回字段；新界面先检查后台能力，避免旧后台忽略快速模式而读取历史。离开页面不额外查询统计，过期响应不覆盖新筛选。
- 验证：36 项订单后端、13 项每日统计后端、27 项统计前端、8 项导航及 5 项模拟重启检查通过（共 89 项）。后端测试使用临时数据库与模拟接口，禁止外网；不代表真实妙手接口耗时实测。
